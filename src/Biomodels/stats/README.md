# BioModels Statistical Analysis and Visualization

## Overview

This R script performs a complete statistical analysis and visualization workflow for infectious disease computational models downloaded from BioModels.

The script processes CSV files generated by the BioModels Python pipeline and automatically produces:

* publication trend analyses
* modelling approach distributions
* file format statistics
* curation quality analyses
* publication period comparisons
* PNG visualizations for all analyses
* summary statistical tables

All figures are exported automatically into an `outputs/` directory.

---

# Features

* Automated generation of publication trend figures
* Comparative analysis across disease categories
* Visualization of modelling approaches
* File extension distribution analysis
* Heatmap generation
* Curation quality assessment
* Publication period comparison (pre/post 2015)
* Automatic PNG export
* Export of summary CSV statistics

# Notes

* Missing or invalid values are automatically filtered.
* Publication years before 1990 are excluded from temporal analyses.
* Unknown modelling approaches are removed from comparative figures.
* Heatmaps and stacked bar plots are normalized where appropriate.
