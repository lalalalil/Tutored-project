# BioModels Analysis Outputs

## Overview

This directory contains all statistical outputs generated by the BioModels infectious disease analysis workflow.

The files were produced using:

* the Python BioModels data extraction and cleaning pipeline
* the R statistical analysis and visualization script

The outputs summarize trends, modelling strategies, repository structure, publication dynamics, and curation quality for infectious disease computational models obtained from BioModels.

# Workflow Origin

The outputs were generated through the following workflow:

```text id="j8r1ty"
BioModels Database
        ↓
Python Download & Cleaning Pipeline
        ↓
CSV Statistical Summaries
        ↓
R Statistical Analysis
        ↓
PNG Figures + Final Summary Tables
```

---

# Notes

* Some figures use normalized percentages for easier comparison.
* Unknown or incomplete metadata entries are automatically filtered.
* Publication analyses exclude years before 1990.
* Modelling approaches labelled as unknown or unspecified are removed from comparative analyses.
